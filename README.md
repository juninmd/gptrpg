# gptrpg

## Description

A demo of an GPT-based agent existing in an RPG-like environment.

## Installation

1.  Clone the repository: `git clone https://github.com/yourusername/gptrpg`
2.  Navigate to the project directory: `cd gptrpg`
3.  Install dependencies: `npm install`
4.  Run the game: `npm start`

## Usage

*   **Game Setup:**
    *   The `map.png` file represents the game world.  You can interact with the map through the game UI.
    *   The `package-lock.json` and `package.json` files define the project's dependencies and configuration.
    *   The `agent` file contains the GPT-based agent's logic and behavior.
    *   The `ui-admin` file provides the user interface for interaction.
*   **Interaction:**  Use the game UI to `type` commands to the agent.  The agent will respond based on its understanding of the environment and the provided input. Explore the map and experiment with different actions to understand the agent's capabilities.  Consider providing detailed prompts to the agent to test different agent behaviors.
